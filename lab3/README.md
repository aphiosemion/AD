# Лабораторна робота №3: Візуалізація даних

## Опис завдання
Метою лабораторної роботи є набуття практичних навичок роботи з наборами даних та опанування інструментів для побудови графіків мовою Python. Завдання передбачає вибір датасету, його попередню обробку та проведення візуального аналізу. Основний фокус спрямований на створення інформативних діаграм, що демонструють різні типи взаємозв'язків у даних. Робота включає побудову як базових графіків, так і складних багатовимірних візуалізацій із використанням кольорового кодування, зміни розмірів та форм маркерів для відображення додаткових параметрів досліджуваних об'єктів.

---

## Вимоги до системи
Для роботи проєкту необхідний інтерпретатор Python версії 3.9 або вище з попередньо встановленими бібліотеками pandas numpy matplotlib seaborn jupyter. Обробка повного набору даних потребує наявності менеджеру пакетів pip для інсталяції залежностей з файлу `requirements.txt`.

---

## Інструкція із запуску

1. Завантажити з сайту https://archive.ics.uci.edu/datasets датасет Heart Disease
2. Створити віртуальне середовище за допомогою команди `python -m venv venv` та активуйте його (для Windows: `venv\Scripts\activate`, для macOS або Linux: `source venv/bin/activate`).
3. Оновіть менеджер пакетів та встановіть необхідні бібліотеки командою `pip install -r requirements.txt`.
4. Переконайтеся, що папка з датасетом знаходиться у кореневій теці проєкту.
5. Відкрийте Jupyter Notebook  і запустіть файл `lab3`. Виконайте всі клітинки коду послідовно.
