# Лабораторна робота №6: Обробка відеопотоку в реальному часі за допомогою OpenCV

## Опис завдання

Ця робота присвячена розробці застосунку на мові **C++** для захоплення, аналізу та модифікації відеопотоку. У проєкті реалізовано модульну архітектуру, що дозволяє динамічно застосовувати фільтри обробки зображення та керувати параметрами яскравості в реальному часі. Особлива увага приділена автоматизації збірки через **CMake**

---

## Вимоги до системи

Для успішної компіляції та запуску проєкту необхідна ОС **Linux (Ubuntu 24.04)** з встановленими компонентами:
* **GCC/G++** — компілятор з підтримкою стандарту C++17.
* **CMake** (версія 3.10+) — для керування процесом збірки.
* **OpenCV 4.x** — основна бібліотека для комп'ютерного зору.
* **V4L2 (Video4Linux)** — для взаємодії з апаратними відеопристроями.

---

## Інструкція із запуску

Проєкт містить набір скриптів для повної автоматизації розгортання:

1.  **Підготовка системи:** Виконайте `./preinstall.sh`, щоб встановити всі необхідні системні залежності та бібліотеки OpenCV.
2.  **Збірка проєкту:** Запустіть `./build.sh`. Скрипт створить директорію `build`, сконфігурує CMake та скомпілює виконуваний файл.
3.  **Запуск:** Виконайте `./run.sh` для старту програми.
4.  **Налаштування камери:** Для стабільної роботи без артефактів у налаштуваннях віртуальної машини має бути обрано **USB 3.1**

---

## Функціональні можливості

* **Модульна архітектура:** Логіку розділено на незалежні класи: `CameraProvider`, `FrameProcessor`, `KeyProcessor` та `Display`, що забезпечує чистоту коду та легкість розширення.
* **Інтерактивні ефекти:** Підтримка 6 режимів роботи, які перемикаються клавішами **0–5**:
    * **Normal (0):** Оригінальний відеопотік.
    * **Inversion (1):** Ефект негативу.
    * **Canny (2):** Детекція контурів (чорний режим).
    * **Sepia (3):** Стилізація під старе фото.
    * **Pixelate (4):** Динамічна пікселізація зображення.
    * **Posterize (5):** Ефект художнього плакату.
* **Керування параметрами:** Реалізовано інтерактивний слайдер (**Trackbar**) для регулювання яскравості кадру "на льоту".
* **Оптимізація потоку:** Примусове використання бекенду **V4L2** та формату **MJPEG** для забезпечення плавної картинки без затримок.

## Інструкції для користувача

Для взаємодії з програмою використовуйте наступні гарячі клавіші:
* **Цифри 0-5** — зміна режимів обробки зображення.
* **Повзунок Brightness** — регулювання освітленості кадру.
* **Клавіша ESC** — коректне завершення роботи та закриття всіх вікон.
* **Статус-бар** — інформація про поточні значення RGB та обраний режим відображається в реальному часі.
