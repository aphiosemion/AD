# Лабораторна робота №5: Наука про дані: обмін результатами та початковий аналіз


## Опис завдання

Ця робота присвячена розробці інтерактивного вебзастосунку на базі фреймворку **Streamlit** для аналізу та візуалізації супутникових даних стану рослинності (індекси VCI, TCI, VHI). У проєкті реалізовано систему динамічного очищення та обробки великих масивів даних за допомогою **Pandas**, а також механізми інтерактивної візуалізації часових рядів. Також було застосовано бібліотеку **Plotly** для створення графіків, що дозволяють отримувати точні значення показників при наведенні курсора без візуального перевантаження інтерфейсу.

---

## Вимоги до системи

Для роботи проєкту необхідний інтерпретатор Python версії 3.9 або вище з попередньо встановленими бібліотеками:
* **pandas** — для маніпуляції даними та очищення CSV-файлів.
* **streamlit** — для побудови веб-інтерфейсу.
* **plotly** — для створення інтерактивних графіків.

Обробка даних потребує наявності вихідних CSV-файлів у папці `vhi_data`.

---

## Інструкція із запуску

1. Створіть віртуальне середовище за допомогою команди `python -m venv venv` та активуйте його (для Windows: `venv\Scripts\activate`).
2. Встановіть необхідні залежності `pip install -r requirements.txt`.
3. Переконайтеся, що файл скрипта та папка `vhi_data` знаходяться в одній директорії (її можна отримати в процесі виконання другої лабораторної роботи).
4. Запустіть програму командою `streamlit run lab5.py`.
5. Використовуйте веб-інтерфейс у браузері для взаємодії з даними.

---

## Функціональні можливості

* **Динамічна фільтрація:** Слайдери та випадаючі списки дозволяють миттєво змінювати часовий діапазон (роки, тижні), обирати область дослідження та тип індексу.
* **Взаємовиключне сортування:** Реалізовано логіку «розумних» чекбоксів, що дозволяють керувати порядком відображення даних у таблиці (за зростанням або спаданням).
* **Інтерактивна візуалізація:** Графік динаміки побудований таким чином, щоб забезпечувати плавну лінію часового ряду з можливістю бачити точний рік та тиждень при наведенні мишки.
* **Порівняльний аналіз:** Автоматична генерація гістограми середніх значень по всіх регіонах України з виділенням обраної області окремим кольором.
* **Кнопка Reset:** Швидке повернення всіх фільтрів та параметрів сортування до початкового стану.

## Інструкції для користувача

Для початку роботи оберіть область та показник у бічній панелі. Використовуйте вкладку **"Таблиця"** для перегляду сирих даних та їх сортування. Перейдіть у вкладку **"Графік динаміки"**, щоб побачити зміни показника протягом обраних років. Завдяки інтерактивності Plotly, ви можете навести курсор на будь-яку ділянку графіка для отримання детальної інформації про конкретний тиждень спостереження. Якщо ви хочете побачити загальну картину по Україні, скористайтеся вкладкою **"Порівняльна діаграма"**.
