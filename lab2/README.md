# Лабораторна робота №2: Наука про дані: підготовчий етап

## Опис завдання
Ця робота присвячена розробці конвеєра обробки великих даних про енергоспоживання домогосподарств із фокусом на складну фільтрацію, профілювання швидкодії коду та підготовку ознак для машинного навчання. У проєкті реалізовано методи масштабування даних через нормалізацію та стандартизацію, проведено статистичний аналіз взаємозв’язків між параметрами мережі та впроваджено техніку One Hot Encoding для трансформації категоріальних атрибутів у векторну форму.

---

## Вимоги до системи
Для роботи проєкту необхідний інтерпретатор Python версії 3.9 або вище з попередньо встановленими бібліотеками pandas, numpy та scikit-learn. Обробка повного набору даних потребує наявності менеджеру пакетів pip для інсталяції залежностей з файлу `requirements.txt`.

---

## Інструкція із запуску

1. Створіть віртуальне середовище за допомогою команди `python -m venv venv` та активуйте його (для Windows: `venv\Scripts\activate`, для macOS або Linux: `source venv/bin/activate`).
2. Оновіть менеджер пакетів та встановіть необхідні бібліотеки командою `pip install -r requirements.txt`.
3. Переконайтеся, що файл із датасетом (`household_power_consumption.txt`) знаходиться у кореневій теці проєкту.
4. Відкрийте Jupyter Notebook або VS Code і запустіть файл `lab2-1.ipynb` або `lab2-2.ipynb`. Виконайте всі клітинки коду послідовно.
