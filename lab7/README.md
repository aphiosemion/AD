# Лабораторна робота №7: Computer Vision та багатопотоковість у C++

## Опис завдання
Ця робота присвячена інтеграції сучасних методів **Deep Learning** у C++ застосунки. Основна мета — реалізація детекції облич у реальному часі за допомогою моделі **ResNet-10 SSD**. 

Головним архітектурним рішенням є винесення важких обчислень нейромережі в окремий потік виконання (`std::thread`). Це дозволяє уникнути блокування інтерфейсу та забезпечує високий FPS відеопотоку, навіть якщо сама нейромережа працює повільно.

---

## Вимоги до системи
Для успішної роботи проекту необхідні:
* **ОС:** Ubuntu 24.04 (або інша Linux-дистрибуція).
* **Компілятор:** G++ з підтримкою стандарту **C++17**.
* **Бібліотеки:** OpenCV 4.x (з модулем DNN) та pthread.

---

## Інструкція із запуску
1. **Підготовка системи:** Виконайте `./preinstall.sh`. Скрипт встановить залежності та автоматично завантажить файли нейромережі через `wget`.
2. **Збірка проєкту:** Виконайте `./build.sh`
3. **Запуск:** Виконайте `./run.sh` 
4. **Керування:** Натисніть клавішу **'F'**, щоб активувати або деактивувати AI-детектор.

---

## Технологічний стек та архітектура
* **Багатопотоковість (Multithreading):** * **Головний потік (UI):** Займається рендерингом відео та обробкою клавіш. Забезпечує плавну картинку.
    * **Фоновий потік (Worker):** Клас `FaceDetector` обробляє кадри нейромережею SSD. 
* **Синхронізація (Concurrency):** Безпека даних реалізована через `std::mutex` та `std::lock_guard`, що запобігає стану гонитви (race condition) при доступі до кадрів.
* **OpenCV DNN:** Використання сучасного детектора на базі ResNet-10, який працює стабільніше за класичні методи (наприклад, каскади Хаара).

## Керування
* **F** — увімкнути/вимкнути розпізнавання облич.
* **0-5** — перемикання режимів візуальних фільтрів.
* **ESC** — вихід із програми.
* **Trackbar** — налаштування яскравості в реальному часі.
