# Лабораторна робота №4: Обробка та візуалізація сигналів


## Опис завдання

Ця робота присвячена розробці інтерактивної системи для моделювання та аналізу гармонійних сигналів із застосуванням методів цифрової фільтрації. У проєкті реалізовано генерацію функції гармоніки виду $y(t) = A \cdot \sin(\omega t + \phi)$, впроваджено алгоритм накладання адитивного гаусового шуму та розроблено механізм очищення сигналу за допомогою фільтра низьких частот Баттерворта. Ключовою особливістю є динамічне оновлення параметрів через графічний інтерфейс без перегенерації незмінних компонентів даних.

---

## Вимоги до системи

Для роботи проєкту необхідний інтерпретатор Python версії 3.9 або вище з попередньо встановленими бібліотеками `numpy`, `matplotlib` та `scipy`. Обробка та візуалізація даних потребує наявності менеджера пакетів `pip` для інсталяції залежностей.

---

## Інструкція із запуску

1. Створіть віртуальне середовище за допомогою команди `python -m venv venv` та активуйте його (для Windows: `venv\Scripts\activate`, для macOS або Linux: `source venv/bin/activate`).
2. Встановіть необхідні бібліотеки командою `pip install -r requirements.txt`.
3. Переконайтеся, що файл скрипта `lab4.py` знаходиться у кореневій теці проєкту.
4. Запустіть програму командою `python lab4.py`. Використовуйте графічний інтерфейс для взаємодії з графіками.

---

## Функціональні можливості

* **Слайдери керування:** Дозволяють змінювати амплітуду, частоту та фазу гармоніки, а також параметри середнього значення та дисперсії шуму в реальному часі.
* **Інтерактивні чекбокси:** Керування відображенням зашумленого сигналу та результатів фільтрації на головному полі графіка.
* **Цифрова фільтрація:** Використання `scipy.signal.filtfilt` для отримання фазово-коректного очищеного сигналу, максимально наближеного до оригіналу.
* **Кнопка Reset:** Миттєве відновлення початкових значень усіх параметрів системи до дефолтного стану.

---

## Інструкції для користувача

Для початку роботи запустіть скрипт. Ви побачите вікно з чистим гармонійним сигналом. За допомогою чекбоксів увімкніть відображення шуму та фільтра. Використовуйте повзунки для дослідження того, як висока дисперсія шуму впливає на точність відновлення сигналу фільтром. Якщо графік став занадто складним для сприйняття, натисніть **Reset**.
